# hotsearch
为校园增添随心管理的热搜榜，与classisland搭配使用
## 部署指南
要部署hotsearch，你需要以下前置准备
- windows 10/11
- 安装Classisland
- 在Classisland中安装HTTP插件
- 拥有一个域名并将其绑定到Resend服务（可选）
- 注册Ngrok服务(可选)
